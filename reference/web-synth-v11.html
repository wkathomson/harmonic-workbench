MIDI: waiting for power Latch + Arp on · right-click a knob to MIDI learn · Clockwork / Filament
v11 — the big one. Arpeggiator: the last hard part from the spec. A setTimeout loop wakes every 25ms and schedules any steps falling inside a 100ms window onto the audio clock — the "two clocks" pattern. Timer jitter is absorbed by the window; the notes land sample-accurate. Latch a chord, engage the arp, and the synth plays itself. FM: osc 2's output routed into osc 1's frequency param. That's the whole mechanism — one gain node between two oscillators — and it produces the entire metallic universe. Depth is an AudioParam, so the matrix drives it: Filament sends the aux envelope at −55%, so each note starts bright and clangs down into a sine, which is what a struck bell does. Aux envelope: a per-voice ConstantSource whose offset is the envelope — a normalised 0..1 mod source. It's per-voice, so the matrix wires voice i's envelope to voice i's parameter rather than fanning one node across all eight; each note modulates only itself. This is the refactor that unlocks env → pulse width, env → FM, env → pitch. Wavetable interpolation: each oscillator unit now runs two oscillators holding adjacent tables, crossfaded by the fractional morph position. Sweeps are continuous, and each oscillator's table only ever changes while its own gain is near zero, so reloading never clicks. Chorus: two short delays modulated in opposition and panned wide — the same time-varying detune that makes the PWM strings work, applied to anything. Stereo spread fans the voice pool across the image; Record taps the master into a MediaRecorder and downloads what you played; A/B holds two patches for comparison; and right-clicking any knob arms MIDI learn — move a CC and it's mapped.
